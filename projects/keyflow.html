KeyFlow

A typing speed test that shows your speed and accuracy as you type.

Role
Design and development
Built
July 2025
Stack
HTML, CSS, JavaScript
Live site (opens in a new tab) Source code (opens in a new tab)

Overview

I built KeyFlow to practise handling keyboard events and updating the page on every keystroke. A typing test is a good small project for this, because everything depends on timing and on reacting to each key press.

Unlike my other early projects, the code is split into separate HTML, CSS and JavaScript files.

What it does

  • Pick a random sentence from a set of prompts.
  • Start the test from the button or the first key press.
  • Mark each character as correct, incorrect or current as you type.
  • Show words per minute, accuracy and elapsed time live, then a results screen.
  • Reset or start a new test at any time, with a saved light or dark theme.

How it works

Speed uses the standard rule that five characters make one word: correct characters divided by five, divided by the minutes elapsed. Accuracy is correct characters divided by characters typed.

Typing is capped at the prompt's length, and the test ends when the last character is entered. A timer updates the clock every 100 milliseconds.

The tricky parts

Redrawing on every key

The prompt is rebuilt as one span per character on each keystroke so every letter can be styled. It works for short sentences but would not scale to long texts.

Test states

The app moves between ready, typing and results screens, and each move has to reset the timer, the stats and the input without leaving anything behind.

Honest numbers

WPM only counts correct characters, so mistakes lower the score, which makes the result a more honest measure of typing.

What I would improve

  • Track every keystroke, not just the current text, so accuracy still reflects mistakes that were corrected with backspace.
  • Wire up the sound toggle. It saves its setting and changes its icon, but no sound plays yet. I would add key sounds or remove the button.
  • Update only the characters that change instead of rebuilding the whole prompt.
  • Add more prompts, timed modes and a saved personal best.
  • Announce the results to screen readers and test with mobile keyboards.
